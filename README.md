# PP_TP1_53447

El proyecto es una aplicación desarrollada en Java para la administración de eventos universitarios. El sistema permite registrar eventos, asignarles salas, gestionar actividades específicas y registrar las inscripciones de los estudiantes.

Para ejecutar el proyecto:
- Clonar este repositorio localmente.
- Abrir el proyecto utilizando IntelliJ.
- Compilar y ejecutar la clase Main

* Aclaración * Las salidas las puse en una carpeta porque era muy extensa y no podia dejarla en una sola captura, van desde la 1.1 a la 1.4 en orden.
